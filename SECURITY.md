# Security

LoveFinder is a personal project shared for viewing and development. I don’t have the resources to operate or continuously monitor a hosted backend, provide security support, or guarantee that the code is secure or suitable for real users’ sensitive data. The backend and related services may be unavailable or broken.

## Reporting a vulnerability

Please do not post suspected vulnerabilities, exploit details, credentials, or private data in a public issue or pull request.

If GitHub’s private vulnerability reporting is enabled for this repository, use the repository’s **Security** tab to report the issue privately. Otherwise, contact me through my GitHub profile at https://github.com/pxrxp and ask for a private way to share the details. Please include the affected area and a description of the issue, but do not include real users’ data or secrets.

I’ll review reports as I’m able, but there is no guaranteed response time, fix, or security-update schedule.
