# Code of Conduct

LoveFinder is a personal project. Anyone interacting with the project is expected to be respectful and constructive.

Examples of behavior that help keep project discussions welcoming:

- Be considerate and respectful.
- Discuss code and ideas without personal attacks.
- Respect differing viewpoints and experience levels.
- Do not share someone’s private information, credentials, or personal data.

Harassment, discrimination, threats, doxxing, and repeated unwanted contact are not acceptable in project discussions or contributions.

If you have a concern about behavior in a project space, contact me privately through my GitHub profile: https://github.com/pxrxp. I’ll review reports as I’m able. This is a personal project, so responses may not be immediate.
